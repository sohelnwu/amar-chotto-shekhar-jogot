# আমার ছোট্ট শেখার জগৎ (Amar Chotto Shekhar Jogot)

৩–৬ বছরের শিশুদের জন্য বাংলা-প্রধান, অফলাইনে চলা শেখার অ্যাপ (Android PWA)।
ছবিতে ছুঁলেই পরিষ্কার বাংলা কণ্ঠে নাম ও পরিচিতি শোনায় — নারী ও পুরুষ দুই কণ্ঠে।

## দ্রুত শুরু (এই কম্পিউটারে)

Node.js পোর্টেবলভাবে `D:\claude\_buildtools\node`-এ রাখা আছে। প্রতিটি নতুন PowerShell উইন্ডোতে প্রথমে:

```powershell
$env:Path = "D:\claude\_buildtools\node;" + $env:Path
```

তারপর প্রজেক্ট ফোল্ডারে:

```powershell
cd D:\claude\amar-chotto-shekhar-jogot
```

| কাজ | কমান্ড |
|---|---|
| ডেভেলপমেন্ট সার্ভার (http://localhost:5173) | `npm run dev` |
| প্রোডাকশন বিল্ড (`dist/` ফোল্ডারে) | `npm run build` |
| বিল্ড দেখা (http://localhost:4173, service worker সহ) | `npm run preview` |
| ইউনিট টেস্ট (Vitest) | `npm test` |
| এন্ড-টু-এন্ড টেস্ট (Playwright, Edge দিয়ে; আগে `npm run build`) | `npm run test:e2e` |
| টাইপ চেক | `npm run typecheck` |

অন্য কম্পিউটারে: [Node.js LTS](https://nodejs.org) ইনস্টল করে `npm install`।

## Android ফোনে ইনস্টল

PWA ইনস্টল ও অফলাইনের জন্য **HTTPS** দরকার। সবচেয়ে সহজ উপায়:

1. `npm run build` চালান।
2. `dist` ফোল্ডারটি যেকোনো স্ট্যাটিক হোস্টিংয়ে দিন — যেমন Netlify (app.netlify.com/drop-এ ফোল্ডার টেনে ছাড়ুন), Cloudflare Pages বা GitHub Pages। অ্যাপ `HashRouter` ও আপেক্ষিক পাথ ব্যবহার করে, তাই যেকোনো সাব-ফোল্ডারেও চলবে, আলাদা সার্ভার-সেটিং লাগবে না।
3. ফোনে Chrome দিয়ে লিংকটি খুলুন → মেনু (⋮) → **Install app / হোম স্ক্রিনে যোগ করুন**।
4. অ্যাপ খুলে **অভিভাবক → ডাউনলোড** থেকে দরকারি অডিও প্যাক নামান (Wi-Fi-তে)। এরপর ইন্টারনেট ছাড়াই চলবে।

> বাসার Wi-Fi-তে `http://192.168.x.x` দিয়ে খুললে অ্যাপ দেখা যাবে, কিন্তু Chrome HTTPS ছাড়া অফলাইন/ইনস্টল চালু করে না।

অ্যাপের নতুন সংস্করণ হোস্ট করলে ফোনে "অ্যাপের নতুন সংস্করণ এসেছে — আপডেট" বার্তা আসবে।

## বিষয়বস্তুর ফরম্যাট ও নতুন কিছু যোগ করা

বিভাগ: `src/content/categories.json`। কার্ড: `src/content/items/*.json` (প্রতি ফাইলে `{ "<categoryId>": [ ... ] }`)।

```json
{ "id": "mango", "bn": "আম", "en": "Mango", "emoji": "🥭",
  "desc": "আম একটি মিষ্টি ফল।", "level": 1,
  "related": ["banana"], "image": "images/fruits/mango.webp", "sound": "animals/cow.mp3" }
```

| ঘর | মানে |
|---|---|
| `id` | ছোট হাতের ইংরেজি, `-` চলবে; অডিও ফাইলের নামও এটাই |
| `bn`, `en`, `desc`, `descEn` | বাংলা নাম, ইংরেজি নাম, বাংলা পরিচিতি, (ঐচ্ছিক) ইংরেজি পরিচিতি |
| `level` | ১, ২ বা ৩ |
| `emoji` / `symbol` / `swatch` / `shape` / `image` | ছবি হিসেবে যা দেখাবে (`image` থাকলে সেটাই আগে; না পেলে emoji) |
| `sayBn`, `sayEn` | উচ্চারণের জন্য আলাদা লেখা (যেমন `ণ` → "মূর্ধন্য ণ") |
| `count` | সংখ্যার কার্ডে কয়টা জিনিস দেখাবে |
| `related` | সম্পর্কিত কার্ডের id |
| `sound` | `public/sounds/`-এর ভেতরে আসল শব্দের ফাইল |

যোগ করার পর:

```powershell
D:\claude\_buildtools\venv\Scripts\python.exe scripts\generate_audio.py
```

এটা শুধু নতুন/বদলানো লেখার অডিও বানায় (`edge-tts` লাগে, ইন্টারনেট লাগে), তারপর `audio-manifest.json` হালনাগাদ করে। `npm test` চালালে ভুল id, হারানো অডিও, ভুল related ইত্যাদি ধরা পড়বে।

## নিজের রেকর্ড করা কণ্ঠ বা আসল প্রাণীর ডাক ব্যবহার

- **নিজের কণ্ঠ:** একই নামে MP3 ফাইলটি বদলে দিন (যেমন `public/audio/bn/female/fruits/mango.mp3`), তারপর শুধু ম্যানিফেস্ট হালনাগাদ করুন:
  ```powershell
  D:\claude\_buildtools\venv\Scripts\python.exe scripts\generate_audio.py --scan
  ```
  সতর্কতা: পরে ওই কার্ডের লেখা বদলে আবার পূর্ণ generate চালালে ফাইলটি নতুন TTS দিয়ে বদলে যাবে।
- **আসল প্রাণী/যানবাহনের শব্দ:** অ্যাপে এখন কোনো আসল রেকর্ডিং নেই (লাইসেন্স ছাড়া কিছু রাখা হয়নি)। পশুর ডাক এখন পরিচিতির ভেতরে বলা হয় ("গরু হাম্বা হাম্বা ডাকে")। আসল শব্দ যোগ করতে: লাইসেন্স-মুক্ত (যেমন CC0) MP3 `public/sounds/animals/cow.mp3`-এ রাখুন, কার্ডে `"sound": "animals/cow.mp3"` লিখুন, তারপর `--scan`। তখন কার্ডে "আসল ডাক" বোতাম নিজে থেকে দেখাবে। ফাইল না থাকলে বোতামটি দেখায়ই না।
- **ছবি:** এখন ছবি হিসেবে ইমোজি ব্যবহার হচ্ছে (অফলাইন, হালকা, লাইসেন্স-ঝামেলা নেই)। নিজের/লাইসেন্সকৃত ছবি `public/images/`-এ রেখে কার্ডে `"image"` দিন। ছবি লোড না হলে ইমোজি দেখাবে।

## অডিও কীভাবে কাজ করে

1. প্রতিটি বাটন জানে তার অডিও ফাইল আছে কিনা (`audio-manifest.json`)।
2. চাপ দিলে আগে ফোনের ক্যাশ (ডাউনলোড করা প্যাক) থেকে, না থাকলে ইন্টারনেট থেকে আনে এবং পরের বারের জন্য জমা রাখে।
3. ফাইল না পেলে — এবং অভিভাবক TTS চালু রাখলে ও ফোনে ওই ভাষার কণ্ঠ থাকলে — ফোনের TTS দিয়ে বলে।
4. তাও না হলে বাটন ধূসর হয় এবং "এই অডিওটি এখন নেই…" দেখায়। অডিও বাজছে বলে ভান করে না।
5. একটার বেশি অডিও কখনও একসাথে বাজে না; অ্যাপ পেছনে গেলে অডিও থামে।

## টেস্ট

- `npm test` — ৩২টি ইউনিট টেস্ট: বিষয়বস্তু যাচাই, প্রতিটি কার্ডের সব অডিও আছে কিনা, অডিও ইঞ্জিন (ওভারল্যাপ নেই, অনুপস্থিত অডিও, TTS ফলব্যাক, pause/resume), IndexedDB, খেলার লজিক, প্যাক, অভিভাবক-গেট।
- `npm run test:e2e` — ৩৪টি ব্রাউজার টেস্ট Android ফোন (Pixel 7) ও ট্যাবলেট সাইজে: সব বিভাগ খোলে কিনা, ফ্ল্যাশকার্ড, নারী/পুরুষ কণ্ঠ, আসলে অডিও বাজে কিনা, প্রিয় রিলোডের পরও থাকে কিনা, অভিভাবক সুরক্ষা ও লেভেল, অগ্রগতি রিসেট, খেলা শেষ করা, PWA manifest/আইকন/service worker, **নেটওয়ার্ক বন্ধ রেখে** অ্যাপ চলা ও ডাউনলোড করা অডিও বাজা, অনুপস্থিত অডিওর সৎ বার্তা, স্ক্রিন থেকে বাইরে কিছু না যাওয়া ও ছোট টাচ-টার্গেট না থাকা।
- স্থানীয় Edge দিয়ে চলে; Chrome দিয়ে চালাতে: `$env:PW_CHANNEL='chrome'; npm run test:e2e`।

## জেনে রাখুন (সীমাবদ্ধতা)

- কণ্ঠগুলো Microsoft-এর neural TTS (বাংলা: Nabanita ও Pradeep; ইংরেজি: Ana ও Guy) দিয়ে তৈরি। বেশিরভাগ উচ্চারণ ভালো, তবে কিছু একক বর্ণ (যেমন ঋ, ঙ, ঞ, ৎ) একবার নিজে শুনে দেখুন; দরকার হলে নিজের রেকর্ডিং দিয়ে বদলান।
- এই অডিও পরিবারের ব্যক্তিগত ব্যবহারের জন্য ঠিক আছে। অ্যাপটি প্লে-স্টোর বা জনসাধারণের জন্য প্রকাশ করতে চাইলে নিজের রেকর্ডিং বা বাণিজ্যিক লাইসেন্সসহ TTS (যেমন Azure Speech) ব্যবহার করুন।
- ইমোজির চেহারা Android সংস্করণভেদে একটু আলাদা হতে পারে; খুব পুরোনো Android-এ নতুন কিছু ইমোজি (যেমন 🪷 শাপলা) নাও দেখাতে পারে।
- অভিভাবক-গেট একটা গুণের প্রশ্ন — ছোট শিশুকে আটকানোর জন্য, নিরাপত্তা-তালা নয়।
- সব অডিও একসাথে প্রায় ৪২ MB (এক কণ্ঠে প্রায় ২১ MB)।
